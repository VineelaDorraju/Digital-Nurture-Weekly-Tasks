# Employee Management System using PL/SQL

## Project Description

This project is a simple Employee Management System developed using Oracle PL/SQL. The main purpose of the project is to understand how PL/SQL extends SQL by adding programming features such as variables, conditions, loops, exception handling, procedures, functions, packages, and triggers.

The project starts by creating the required database tables and inserting sample employee data. After setting up the database, different PL/SQL programs are written to perform common employee-related operations such as retrieving employee details, updating salaries, processing multiple records, handling errors, and automatically maintaining logs whenever employee information is modified.

Instead of keeping all the logic inside SQL statements, PL/SQL is used to make the database smarter by adding business rules and reusable program units. Each file in this project focuses on one important PL/SQL feature, making it easy to understand how different concepts work together in a real application.

Although this is a beginner-level project, it follows the basic workflow of a real Employee Management System where data is stored, updated, validated, processed, and monitored inside the database.

---

## Project Workflow

1. Create the required database tables.
2. Insert sample employee records.
3. Retrieve employee information using PL/SQL variables.
4. Read complete employee records using record variables.
5. Update employee salaries.
6. Apply conditions to categorize employee salaries.
7. Process multiple employee records using loops.
8. Handle runtime errors using exception handling.
9. Retrieve records efficiently using explicit cursors.
10. Create reusable stored procedures.
11. Create functions that return useful information.
12. Organize procedures and functions using packages.
13. Automatically maintain employee activity using database triggers.

## Concepts Used

### Variables and Data Types

Variables are used to temporarily store values retrieved from the database. `%TYPE` is used so that variables automatically use the same data type as table columns.

### Record Variables

`%ROWTYPE` allows an entire row from a table to be stored in a single variable, making it easier to work with complete employee records.

### Anonymous PL/SQL Blocks

Most examples are written as anonymous blocks to demonstrate how PL/SQL code is executed without permanently storing it in the database.

### Conditional Statements

`IF`, `ELSIF`, and `ELSE` statements are used to make decisions based on employee salary values.

### Loops

FOR loops are used to process multiple employee records one by one without writing repeated SQL statements.

### Exception Handling

Exceptions are used to prevent the program from stopping unexpectedly. The project demonstrates handling predefined exceptions such as `NO_DATA_FOUND`.

### Cursors

Explicit cursors are used to retrieve multiple rows from a query. The project demonstrates the complete cursor lifecycle using `OPEN`, `FETCH`, and `CLOSE`.

### Stored Procedures

Procedures are created to perform reusable operations, such as displaying employee information, without rewriting the same code.

### Functions

Functions are used when a PL/SQL program needs to return a value, such as retrieving an employee's salary.

### Packages

Packages are used to group related procedures and functions together, improving code organization and reusability.

### Triggers

Triggers execute automatically whenever a specific database event occurs. In this project, a trigger records employee updates in a log table whenever salary information is modified.
