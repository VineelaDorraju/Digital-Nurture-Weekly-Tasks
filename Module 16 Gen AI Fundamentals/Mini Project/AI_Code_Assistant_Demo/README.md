# AI Code Assistant Demo

## Overview

A Java-based mini project that demonstrates the fundamentals of Generative AI through prompt processing, code generation, and code review.

## Features

- Prompt-based code generation
- Basic code review
- Modular Java design
- JUnit 5 test cases

## Technologies

- Java
- JUnit 5
- Generative AI Concepts

## Project Structure

- `src/` – Application source code
- `prompts/` – Sample AI prompts
- `tests/` – Unit tests
