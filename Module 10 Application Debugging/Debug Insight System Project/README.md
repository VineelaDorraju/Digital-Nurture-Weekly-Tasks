# Debug Suite

A lightweight debugging-focused project designed to explore real-world issues like API failures, rendering bugs, and state inconsistencies.

## Features
- API status tracking
- Debug hooks and logging utilities
- Performance monitoring scripts
- Simulated bug scenarios

## Setup
npm install  
npm run dev  

## Scripts
- npm run dev
- npm run build
- npm run test
