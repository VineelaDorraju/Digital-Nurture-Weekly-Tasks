# DevOps CI/CD Project – Java

## Overview

This project demonstrates a basic DevOps workflow using a Java application integrated with CI/CD pipelines, containerization, and deployment practices.

## Features

* Java-based HTTP service
* Health check endpoint
* Automated testing
* Docker containerization
* CI/CD using GitHub Actions and Jenkins
* Environment-based configuration

## Tech Stack

* Java (OpenJDK 21)
* Docker & Docker Compose
* GitHub Actions
* Jenkins

## Summary

This project showcases how development, testing, and deployment are automated using DevOps practices and CI/CD pipelines.
